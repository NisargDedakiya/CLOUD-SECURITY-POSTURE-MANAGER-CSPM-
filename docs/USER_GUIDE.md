# Aegis Enterprise CNAPP Platform — End User & Analyst Guide

## 1. Navigating the Security Workspace
- **Executive Overview**: High-level security score, critical risk counters, MTTR, and monthly trends.
- **Security Knowledge Graph**: Interactive graph showing resource blast radius and connected IAM trust paths.
- **Findings & AI Fixes**: Filter findings by severity and click **🤖 AI Fix** to generate instant AWS CLI commands, Console steps, and Terraform drop-in HCL code.
- **Compliance & Exporters**: Generate and download auditor-ready PDF, CSV, JSON, and Excel compliance evidence reports across CIS, SOC 2, ISO 27001, PCI DSS, FedRAMP, GDPR, DORA, and NIS2.
