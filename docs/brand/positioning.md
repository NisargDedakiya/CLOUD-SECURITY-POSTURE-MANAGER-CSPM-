## One-liner
**Aegis — Cloud security posture, on autopilot.**

## What it is (elevator pitch)
Aegis continuously audits a company's AWS, GCP and Azure accounts against CIS
Benchmarks and the compliance frameworks their auditors care about (SOC 2, ISO
27001, PCI DSS), surfaces misconfigurations with fix-it guidance, and watches for
drift — all read-only and non-intrusive.

## Who it's for (ICP)
- **Primary:** Series A–C startups on AWS (10–200 engineers) pursuing SOC 2 and
  needing to satisfy enterprise-customer security reviews.
- **Secondary:** Cloud/platform & security teams at mid-market companies that
  can't justify Wiz/Prisma pricing but have outgrown manual reviews.
- **Economic buyer:** CTO / Head of Security / Head of Compliance.

## The problem (why now)
- Misconfiguration is the most common root cause of cloud incidents.
- Configuration changes daily; point-in-time audits miss the exploit window.
- SOC 2 / ISO evidence collection is manual, painful, and recurring.

## Value proposition
| Pain | Aegis outcome |
|---|---|
| "Is anything public / exposed right now?" | Continuous, prioritized findings with remediation |
| "Prove we're SOC 2 / PCI compliant" | Per-framework score + one-click evidence export |
| "Who changed that security group?" | Drift detection with approve/reject workflow |
| "We can't afford enterprise CSPM" | Transparent self-serve pricing from free |

## Positioning statement
> For engineering and security teams pursuing compliance, **Aegis** is a
> cloud-security-posture manager that continuously finds and helps fix
> misconfigurations across AWS, GCP and Azure — unlike point-in-time audits or
> six-figure enterprise suites, it's continuous, compliance-mapped, and starts free.

## Competitive landscape
- **Wiz / Prisma Cloud / Orca** — powerful, expensive, enterprise sales motion.
  *Aegis wedge:* self-serve, transparent pricing, fast time-to-value.
- **Prowler / Steampipe (OSS)** — free but DIY, no UI/compliance/multi-tenant.
  *Aegis wedge:* productized UX + compliance + drift on top (and we ingest Prowler).
- **AWS Security Hub** — AWS-only, noisy, weak cross-account/compliance UX.

## Voice & visual
- **Tone:** clear, technical, no-FUD. We reduce risk; we don't sell fear.
- **Colors:** indigo→violet gradient (`#4f8cff → #7a5cff`), near-black canvas,
  green for "pass". Logo: shield + check mark (`web/assets/logo.svg`).
